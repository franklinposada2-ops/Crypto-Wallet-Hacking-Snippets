Mission and ethical scope

Wallet security

Wallet architecture and protection

Hot wallets

Connected to the internet with high convenience but lower security.

  • Common risks: malware, phishing, server breaches
  • Best practice: multi-signature and HSM-backed controls

Cold wallets

Offline storage offers a stronger model for custody and key separation.

  • Common risks: physical access and social engineering
  • Best practice: multiple secure backups and restricted access

Hardware wallets

Isolated execution makes them a preferred control for high-risk environments.

  • Common risks: supply-chain tampering and firmware bugs
  • Best practice: verify firmware and trusted sources

Common review checklist

  • Reentrancy and callback vulnerabilities

  • Access control and permission checks

    require(amount > 0, "Insufficient balance");

    (bool success, ) = msg.sender.call{value: amount}("");
    require(success, "Transfer failed");

    balances[msg.sender] = 0;
}
